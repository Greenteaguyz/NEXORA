# Triage Labels & Taxonomy

Standard taxonomy for classifying tickets, tasks, and issues in NEXORA:

| Label | Description |
| :--- | :--- |
| `type:feature` | New user-facing capability or page component |
| `type:bug` | Defect or regression in existing functionality |
| `type:spike` | Exploratory task to research architecture or validate feasibility |
| `type:refactor` | Code restructuring preserving external behavior |
| `type:perf` | Performance optimization (load time, bundle size, Core Web Vitals) |
| `type:a11y` | Accessibility improvements (WCAG AA, keyboard navigation, aria attributes) |
| `area:core` | Core services, data models, state, auth |
| `area:catalog` | Game discovery, search, filtering, genres |
| `area:creator` | Creator studio, publishing, developer profiles |
| `area:detail` | Game detail view, reviews, media carousel, download flow |
