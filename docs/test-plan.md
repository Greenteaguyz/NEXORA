### Critical End-to-End User Journeys

#### 1. The Complete Gated Download Bounce (Showcase Flow)
1. Navigate to `/catalog` as an anonymous user.
2. Select a paid game (e.g. `$4.99`).
3. Click `"Download"` $\rightarrow$ redirects to `/login?returnUrl=/games/{id}`.
4. Log in using seeded account `bob@nexora.io` (buyer role).
5. Application redirects back to `/games/{id}` with state intact.
6. Button now displays `"Buy $4.99"`.
7. Click `"Buy $4.99"` $\rightarrow$ `PurchaseConfirmModalComponent` opens.
8. Click `"Confirm Purchase"` $\rightarrow$ Order created, added to library, file download triggers, button switches to `"Download"`.
9. Navigate to `/library` $\rightarrow$ verify game is listed and re-downloadable.
10. Navigate to `/orders` $\rightarrow$ verify purchase receipt is listed with Order ID, price `$4.99`, and timestamp.

#### 2. Tag Filtering & Debounced Search
1. On `/catalog`, click tag chip `"RPG"` $\rightarrow$ grid instantly filters to RPG games.
2. Type in search bar `"space"` $\rightarrow$ 300ms debounce smoothly updates results without UI stutter.
3. Clear filters $\rightarrow$ catalog returns to full 10 seeded games.

#### 3. Multi-Role & Studio Access Control
1. Log in as buyer-only `bob@nexora.io` $\rightarrow$ header shows only `Catalog`, `Library`, `Orders`, and `Profile`.
2. Manually type `/studio` in browser address bar $\rightarrow$ `roleGuard` intercepts and redirects to `/catalog`.
3. Log in as creator `carol@nexora.io` $\rightarrow$ header displays `Creator Studio`.
4. Access `/studio` $\rightarrow$ listings table displays Carol's games only.

#### 4. Help & Support Center with Privacy Notice
1. Navigate to `/support` (or click "Privacy" in the footer $\rightarrow$ jumps to `/support#privacy`).
2. Click on FAQ accordion items $\rightarrow$ answers expand smoothly.
3. Submit a support ticket $\rightarrow$ confirmation banner appears with a generated ticket reference ID.
4. Verify Privacy & Data Trust Notice card displays local storage data policy, mock transaction safety, and DRM-free delivery guarantee.

#### 5. User Profile & Demo State Reset
1. Navigate to `/profile` as `alice@nexora.io`.
2. Verify role badges display both `[ Buyer ]` and `[ Creator ]`.
3. Click **"Reset Demo Database to Default Seed"** $\rightarrow$ clears mock IndexedDB and restores default 10 games, 3 users, and seed library entries.

#### 6. 404 Wildcard Error Fallback
1. Type a non-existent URL (e.g. `/invalid-page-url` or `/games/non-existent-id`).
2. Verify `NotFoundComponent` renders with friendly error graphics and a `[ Back to Catalog ]` CTA.

#### 7. Genre Directory Navigation
1. Navigate to `/genres` $\rightarrow$ verify all category cards render with live game count badges.
2. Click on the `"RPG"` genre card $\rightarrow$ routes to `/catalog?tag=RPG` with catalog pre-filtered.

#### 8. Wishlist Bookmarking & Acquisition
1. Log in as `alice@nexora.io` $\rightarrow$ click heart icon on an unowned game card.
2. Navigate to `/wishlist` $\rightarrow$ verify game appears in the saved games grid.
3. Click heart icon again $\rightarrow$ game smoothly un-bookmarks and is removed from wishlist.

#### 9. Creator Portfolio Storefront
1. On `/games/game_001`, click on the creator link (`"Created by Carol"`).
2. Verify browser navigates to `/creators/usr_carol` showing Carol's avatar, bio, `[ Creator ]` badge, and all 4 games published by Carol.
